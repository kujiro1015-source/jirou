# KUJIRO Dashboard

黒基調の個人用ダッシュボード。HTML / CSS / JavaScriptだけで動作します。

## 起動方法
1. `index.html` をブラウザで開きます。
2. VS Codeで編集する場合は、3ファイル（`index.html`, `style.css`, `app.js`）を同じフォルダに置きます。
3. 必要ならVS CodeのLive Server拡張機能でローカル表示します。

## 現在の機能
- 日付・時計
- 現金・投資資産の手動入力と合計
- 習慣チェック（日付別）
- メモ／短い日記の保存、編集、削除
- JSONバックアップの書き出しと読み込み
- PCとスマホの画面サイズに対応

## 注意
- データはブラウザの `localStorage` に保存されます。ブラウザのデータを消すと記録も消える場合があります。定期的にバックアップしてください。
- `localStorage` は端末間で自動同期されません。HPとPixelで同じ記録を使うには、後で同期用バックエンド等が必要です。
- 天気とニュースはまだ接続していません。画面上のプレースホルダーです。
- APIキーやパスワードなどの秘密情報は、このリポジトリに置かないでください。
